# Roadmap

## Current focus

- Improve backup and restore reliability with versioned backup metadata.
- Polish PWA install support and offline app behavior.
- Refine theme consistency for dialogs, selection menus, and project modals.
- Stabilize the local study workspace experience on desktop browsers.

## Short-term goals

- Add screenshot support and improved study session summaries.
- Complete full keyboard navigation across reader and annotation workflows.
- Add richer filtering for notes, highlights, collections, and projects.
- Expand knowledge graph connections between notes, bookmarks, and prayers.

## Mid-term goals

- Support additional public-domain devotional works.
- Add export/import for filtered subsets of workspace data.
- Improve offline search performance across larger data sets.
- Add user settings for default highlight colors and theme accents.

## Long-term goals

- Add optional cloud sync while preserving local-first privacy.
- Add multi-window or split-view reading support.
- Add a configurable study timer and session analytics.
- Explore optional liturgical calendar or readings-of-the-day integration.

## Notes

- The project is intentionally scoped as a single-user, local-first app.
- No backend or authentication is planned for the initial release.
- Public-domain texts are preferred to avoid licensing complications.
